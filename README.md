## 📌 Project Overview

Employee attrition leads to significant recruitment costs, reduced productivity, and operational disruptions. This project focuses on analyzing workforce demographics, compensation, departmental performance, job satisfaction, and overtime trends to identify potential factors influencing employee resignations.

The analysis covers **75 employees across 6 Indian branches** and aims to uncover key attrition patterns through Exploratory Data Analysis (EDA), Machine Learning, and interactive data visualization.

The project also develops an explainable attrition prediction pipeline to support data-driven employee retention strategies.
